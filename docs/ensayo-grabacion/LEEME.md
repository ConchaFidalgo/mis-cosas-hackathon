# Ensayo de grabación de Mis Cosas

Material exclusivamente ficticio. Abrir la app en Chrome o Edge, en una ventana amplia. La app es web: no necesitas instalar un programa de escritorio.

1. Entrar en Mis cosas y pulsar Añadir objeto. Nombre: Cafetera de prueba; categoría: Electrodomésticos; ubicación: Cocina; conservación: Usado, en buen estado.
2. Añadir fotos: seleccionar foto-objeto.webp de esta carpeta. Añadir documentos: seleccionar factura-ficticia.pdf. Guardar.
3. Abrir el objeto, Garantías, Añadir garantía. Proveedor: Tienda ficticia. Seleccionar la factura en Documentos asociados. Usar fechas ficticias y revisarlas antes de guardar.
4. Prestar a Persona de prueba, comprobar la situación y registrar la devolución.
5. Preparar un anuncio para Vinted y Wallapop, revisar el texto y las fotos y mostrar la previsualización del paquete. El correo está simulado; no afirmar que se ha enviado ni que se ha publicado un anuncio.
6. Mostrar el resumen de Ventas y los avisos de una suscripción ficticia.
7. Cuando esté verificada la conexión privada: cerrar sesión, entrar y mostrar que el objeto se conserva. No grabar el correo, el enlace de acceso, contraseñas ni el panel de claves.

Antes del vídeo final: comprobar cámara y dictado reales si se van a mostrar, tener todo el recorrido ensayado y mantener visibles las etiquetas de demostración. Las fotos se pueden cargar como archivos durante el vídeo.
